## What is this?
**neoNBTModel** is MallardLuna's fork of NBTExplorer's backend (NBTModel), and is the backend that also powers NBTLoupe.

You can look at the **commit history** to see the changes I've done. But do note the commit messages may seem confusing or out-of-place. That's because this **used to be a subdirectory of NBTLoupe**, but I've decided to migrate it to its own repository for **archival and licensing purposes**.
